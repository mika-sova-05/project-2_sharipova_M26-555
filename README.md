# Primitive DB
Консольное приложение, имитирующее работу с базой данных, которое можно установить и запустить как самостоятельный пакет.

## Описание проекта
Primitive DB — учебный проект.
В проекте рассматриваются создание Python-пакета, разработка интерфейса командной строки (CLI) и реализация основных операций управления базой данных.

## Требования
- Python 3.12 или выше
- uv

## Установка
Клонируйте репозиторий и перейдите в директорию проекта.
Установите зависимости и подготовьте виртуальное окружение:

```powershell
uv sync
```

## Запуск
Для запуска приложения выполните команду:

```powershell
uv run project
```

Ожидаемый результат:

```text
DB project is running!
```
