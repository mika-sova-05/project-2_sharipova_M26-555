# Primitive DB

Консольное приложение, имитирующее работу с базой данных, которое можно установить и запустить как самостоятельный Python-пакет.

## Описание проекта

Primitive DB — учебный проект.

В проекте рассматриваются создание Python-пакета, разработка интерфейса командной строки (CLI) и реализация основных операций управления базой данных.

## Требования

- Python 3.12 или выше
- uv

## Установка

Клонируйте репозиторий и перейдите в директорию проекта.

Установите зависимости и подготовьте виртуальное окружение:

```powershell
uv sync
```

## Запуск

Для запуска приложения выполните команду:

```powershell
uv run database
```

После запуска откроется интерактивная консоль базы данных.

## Управление таблицами

Приложение поддерживает следующие команды:

| Команда | Описание |
|---|---|
| `create_table` | Создать таблицу |
| `list_tables` | Показать список таблиц |
| `drop_table` | Удалить таблицу |
| `info` | Показать информацию о таблице |
| `help` | Показать справку |
| `exit` | Завершить работу |

### Создание таблицы

Формат команды:

```text
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип>
```

Поддерживаемые типы данных:

- `int` — целые числа;
- `str` — строки;
- `bool` — логические значения.

Пример:

```text
create_table users name:str age:int is_active:bool
```

Столбец `ID:int` добавляется автоматически.

### Просмотр таблиц

```text
list_tables
```

### Информация о таблице

```text
info users
```

Команда выводит список столбцов, их типы данных и количество записей.

### Удаление таблицы

```text
drop_table users
```

## Работа с записями (CRUD)

Приложение поддерживает основные операции с записями: добавление, просмотр, обновление и удаление.

### Добавление записи (INSERT)

Формат команды:

```text
insert into <имя_таблицы> values (значение1, значение2, ...)
```

Пример:

```text
insert into users values ("Anna", 25, true)
```

Значение `ID` указывать не нужно: программа генерирует его автоматически на основе максимального существующего ID.

### Просмотр записей (SELECT)

Формат команды:

```text
select from <имя_таблицы> [where столбец = значение]
```

Просмотр всех записей:

```text
select from users
```

Просмотр записей по условию:

```text
select from users where age = 25
```

Результат выводится в виде таблицы.

### Обновление записи (UPDATE)

Формат команды:

```text
update <имя_таблицы> set столбец = значение where столбец = значение
```

Пример:

```text
update users set age = 26 where name = "Anna"
```

Команда обновляет значения записей, соответствующих условию `where`.

### Удаление записи (DELETE)

Формат команды:

```text
delete from <имя_таблицы> where столбец = значение
```

Пример:

```text
delete from users where name = "Anna"
```

Команда удаляет записи, соответствующие условию `where`.

## Хранение данных

Метаданные таблиц сохраняются в файле `db_meta.json` в формате JSON.

Записи каждой таблицы хранятся отдельно в директории `data/` в JSON-файлах с именами соответствующих таблиц.

При повторном запуске приложения информация о созданных таблицах и сохранённые записи загружаются из файлов.
